# macOS dağıtımı

Güncel kurulum: [KURULUM.md](kurulum.md#macos).

Kullanıcı LaunchAgent dosyası `plistlib` ile oluşturulur; XML özel karakterleri güvenle kodlanır. Çalıştırılan komut `.venv/bin/python -m deal_watcher.cli run` olur. Kullanıcının GUI oturumu gerekir. Her zaman açık, oturumsuz root LaunchDaemon kurulumu bu paylaşılabilir paketin varsayılanı değildir.
