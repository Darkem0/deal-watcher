# Security policy

## Scope

Deal Watcher yalnızca fırsatları izler ve bildirim üretir. CAPTCHA, proxy,
stealth, fingerprint değiştirme veya erişim kontrolü aşma uygulanmaz. Otomatik
satın alma, sepet veya ödeme işlemi yoktur.

Akakçe canlı erişimi HTTP 403 nedeniyle doğrulanmamıştır ve varsayılan olarak
kapalıdır.

## Reporting

Güvenlik sorunlarını public issue içine secret veya kişisel veri koymadan proje
sahibine özel kanaldan bildirin. Token, chat ID, .env, SQLite ve log dosyalarını
rapora eklemeyin.
